# NightDesk 远控交互升级发布（Windows 1.6.4 / Android 1.3.4）

更新时间：2026-10-28 09:32 KST（Asia/Seoul）

状态：Windows 1.6.4 / 10604、nx-host 0.2.2 与 Android 1.3.4 / code 13 已构建、验证并发布到 AI 更新源。未替换或重启生产桌面，未创建 Git 提交。

## 1. 本版内容

### Android 1.3.4

- 新增“直接定位 / 触摸板”双鼠标模式，侧栏可切换并持久化；触摸板模式带速度加速与边界限制。
- 手势升级：单指滑动移动指针、轻点左键、长按拖动、双指轻点右键、双指横/纵向滚动、松手惯性滑动。
- 输入合并：连续指针移动只发送最新位置，降低 QUIC 输入队列延迟。
- 侧栏实时显示分辨率与 FPS；点击/右键/拖动提供触觉反馈；双指滚动起始阈值按屏幕密度缩放。
- `NxPointer.kt`、`NxTouchGesture.kt`、`RemoteActivity.kt`、`RemoteTouchControls.kt`、`mobile.aar` 已更新。

### Windows 1.6.4 / nx-host 0.2.2

- 被控端收到远端输入后 1.2 秒内自动把采集提升到 30 FPS，空闲回落到用户配置值。
- 新增横向滚轮 `KindWheelH` 协议与 `MOUSEEVENTF_HWHEEL` 注入。
- Windows viewer 支持 Shift+滚轮横向滚动；远端画面内隐藏本机指针，避免与远端合成光标重影。
- nx-host 版本提升到 0.2.2；旧客户端仍兼容，旧主机收到横向滚轮会安全忽略。

## 4. 构建与恢复

```powershell
# Windows：测试、发布、打包
dotnet run --project tests\NightDesk.Tests\NightDesk.Tests.csproj -c Release --no-restore
powershell.exe -NoProfile -File tools\publish-windows.ps1
powershell.exe -NoProfile -File tools\package-windows.ps1 -Version 1.6.4 -VersionCode 10604
```

```bash
# AI：Go / nx-host
cd /home/tony/dev/nightdesk-native-ux-20261028
go test ./... && go vet ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags='-s -w' \
  -o /tmp/nx-host-0.2.2.exe ./cmd/nx-host

# AI：Android release（脚本负责持久签名）
cd /home/tony/dev/nightdesk-android-ux-20261028/android
NIGHTDESK_ANDROID_DIR=$PWD bash scripts/build-ai.sh -q \
  -PnightdeskVersionCode=13 -PnightdeskVersionName=1.3.4

# AI：发布更新源
cd /home/tony/dev/nightdesk-update-feed
python3 publish.py --apk /home/tony/dev/nightdesk-android-ux-20261028/android/app/build/outputs/apk/release/app-release.apk \
  --version-code 13 --version-name 1.3.4 \
  --certificate-sha256 41d3a3e360d8892028d968d5f90bad4541ea7896a36ca08e2560b6330825b767 \
  --min-sdk 29 --notes '...'
python3 publish_windows.py --zip /tmp/nightdesk-windows-1.6.4.zip \
  --version 1.6.4 --version-code 10604 --notes '...'
```

回滚时保留不可变包，只通过备份清单回到上一版；Android 客户端不会自动降级，已安装 code 13 的设备需重新取得 code 12 安装包。不要覆盖同版本 APK/ZIP。
