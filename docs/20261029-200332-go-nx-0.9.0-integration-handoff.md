## NightDesk 兼容适配

- **桌面 v0 指针**：当前 WPF viewer 隐藏本地指针，依赖 host 把鼠标指针绘进远端帧。新版 host 对 v0 会话保持合成；v1 则仅在 viewer 请求 `CapCursor` 时合成。`native/internal/remote/resilience_test.go` 覆盖该分支。
- **Android capability**：Android 通过 `newSessionWithOptions(..., true, ...)` 请求 v1 cursor。若 NightDesk QR host 协商回退到 v0，才调用 `assumeLegacyExtensions()`，保留既有 NightDesk host 的 Text/WheelH 功能；不对未知 v0 host 自动假定能力。
- **WPF trusted 状态**：旧 NightDesk host 返回 `trusted` 指纹到详情对象；上游 host 返回指纹数组。WPF `NxHostEvent` 现在以 JSON 元素接收两类形状。NightDesk hostd 仍输出上游 `trusted` 数组，并附加 `trustedDetails` 对象让 WPF 保留地址/配对时间。两种 JSON 均有回归断言。
- **安全测试模式**：上游 bare `-test-mode` 已默认选择 pattern 源 + log injector（而不是报错退出），因此更新 `tools/test-nx-probe.ps1`，直接断言安全默认值，并容许上游 probe 返回至少 7 个回执。测试脚本 stderr 读取改为异步 task，避免 PowerShell 事件线程缺少 runspace 的异常。
- **颜色/像素约定**：没有修改帧的 BGRA 线上约定或另加 R/B 通道翻转；Go tile/帧测试与 WPF BGRA 像素断言通过。真实 Android 设备上颜色观感仍应复核。
- **不移植按 viewer 尺寸切换 VDD**：协议类型可以识别 `CapVirtualDisplay`/`ViewSize`，但 NightDesk hostd 没有注册 `OnViewSize`，不会对外声明能力。NightDesk 的 `DisplayController`、恢复快照和 Parsec VDD 生命周期已独立存在，不能让两套控制逻辑并行切换或恢复拓扑。

在 NightDesk 根目录：

```powershell
git status --short --branch
git log -1 --oneline
dotnet run --project tests\NightDesk.Tests\NightDesk.Tests.csproj -c Release
.\tools\test-nx-probe.ps1
```

在 SSH AI 主机（当前工作区 `/home/tony/dev/NightDesk`）：

```bash
cd /home/tony/dev/NightDesk/native
go test ./...
go test -race ./mobile ./internal/remote
go vet ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go vet ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build ./...
gomobile bind -target=android -androidapi 29 -o /tmp/mobile.aar ./mobile
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags='-s -w -X main.version=0.9.0+nightdesk' -o /tmp/nx-host.exe ./cmd/nx-host
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags='-s -w' -o /tmp/nx-probe.exe ./cmd/nx-probe
```

Android 版本必须经 `bash android/scripts/build-ai.sh` 构建，以便脚本从 AI 主机已有的签名存储加载密钥；需要构建安全仪器测试 APK 时追加 `assembleAndroidTest`。不要在未确认目标 emulator/服务边界时运行线上 `UpdateFlowInstrumentedTest`。
